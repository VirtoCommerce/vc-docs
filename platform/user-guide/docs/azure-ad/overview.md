# Overview

The **Azure AD** module provides users with a simplified sign-in experience. It allows users to access multiple applications with a single set of credentials, eliminating the need to remember different usernames and passwords for each application.

The Azure AD module integrates Virto Commerce with Entra ID (previously Azure AD) to provide secure authentication and authorization for cloud and on-premises applications. This helps to improve productivity, security, and user satisfaction by reducing the number of times users are prompted for their credentials.

!!! note
    Microsoft renamed Azure Active Directory to **Microsoft Entra ID**. The module and this guide still use the name **Azure AD**, and the two names refer to the same service.

## Key features

* The Azure AD module can be integrated with both the Virto Commerce Platform and the Frontend Application.
* Supports single-tenant and multi-tenant configurations.
