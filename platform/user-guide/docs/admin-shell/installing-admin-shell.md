# Installing and Using Admin Shell

Install the Admin Shell module the same way as [other modules](/platform/user-guide/latest/modules-installation).

## Prerequisites

Before configuring the module, make sure you have:

* [Virto Commerce Platform, version 3.1093.0 or higher](https://github.com/VirtoCommerce/vc-platform/releases/tag/3.1093.0). On an older Platform version, Admin Shell installs but can't take over the back office.

## Use Admin Shell

Once installed, Admin Shell opens at **/apps/admin-shell/** alongside the existing AngularJS back office. An administrator can also set it as the back office that opens by default at the site root. Ask your development team to configure this for your environment.
