# Manage Loyalty Missions

To create a mission:

1. Click **Loyalty missions** in the main menu.
1. In the next blade, click **Add** in the toolbar.
1. In the next blade:

    * Add mission name, localized names, localized descriptions.
    * Select store the mission will be available for.
    * Set start and end dates of the mission.

1. Configure target audience.


1. Set the mission goal. You can set only one goal per mission:

    | Goal type| What you fill in|
    |---|---|
    | Reach target order value| The amount, and the currency it is measured in |
    | Reach target number of orders| The number of orders |
    | Purchase target quantity of SKUs | The mode  (**all** or **any**) then the SKU list |

    !!! note 
        The SKU list is a two-step job. On an unsaved mission the blade shows **You can add SKUs after saving the mission**. Save the mission with the goal type and mode chosen, reopen it, then click select to pick products from the catalog.


1. Add a reward, i.e. set the fixed amount of points per order, for example, 750.00 fixed points. Click Add reward again to attach more than one reward row to the same mission.

1. Click **Save** in the toolbar. The mission appears in the missions blade. After that, the mission becomes uneditable and can only be deleted or archived. 
1. Click **Publish** to make it available to customers on the Frontend. 

Users can now start completing the mission on the Frontend.
