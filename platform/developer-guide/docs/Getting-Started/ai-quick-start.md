# AI Quick Start

Virto Commerce provides three complementary AI-grounding tools. They differ in setup effort and in the stage of work they suit best, from one-off questions to active coding sessions. Pick the one that matches your workflow, or combine all three.

| Tool            | Effort                                  | Best for                                                                  |
|-----------------|-----------------------------------------|---------------------------------------------------------------------------|
| [Virto OZ](/platform/user-guide/virto-oz)       | Zero install, built into the docs site.  | Browsing-while-reading, step-by-step guides with links to actual articles. |
| [llms.txt](../Tutorials-and-How-tos/How-tos/using-llms-txt.md)    | Zero install, works in any chat.        | One-off questions, evaluating Virto Commerce, no tooling commitment.       |
| [Context7 MCP](../Tutorials-and-How-tos/How-tos/using-context7.md)  | One-time MCP install in your editor.     | Active coding sessions, persistent project work, code generation.         |
