# SearchHistoryResultType ==~object~==

This type defines the structure of the response for a search history query.

## Fields

| Field                   | Description                                                                    |
| ----------------------- | ------------------------------------------------------------------------------ |
| `queries` ==[String]== | A list of the user's recent search queries, ordered from most to least recent. |
