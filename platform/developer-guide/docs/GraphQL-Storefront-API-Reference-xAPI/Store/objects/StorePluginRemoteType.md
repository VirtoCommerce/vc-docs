# StorePluginRemoteType ==~object~==

This type represents the Module Federation remote coordinates a frontend host app uses to load a store plugin.

## Fields

| Field          | Description                                       |
|----------------|-----------------------------------------------------|
| `name` ==String==    | Module Federation remote name.                |
| `exposed` ==String== | Exposed module path, e.g. `./Module`.          |
