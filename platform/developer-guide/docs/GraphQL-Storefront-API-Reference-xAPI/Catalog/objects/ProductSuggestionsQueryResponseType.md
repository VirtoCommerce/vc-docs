# ProductSuggestionsQueryResponseType  ==~object~==

This type represents the response returned by the `productSuggestions` query, typically used for providing autocomplete product name suggestions.

## Fields

| Field                       | Description                                                   |
| --------------------------- | ------------------------------------------------------------- |
| `suggestions` ==[String]==  | A list of product name suggestions based on the search query. |
