# CustomerCartStatisticsPeriodType ==~object~==

This type reports aggregated cart figures for a date range.

## Fields

| Field | Description |
|-------|-------------|
| `count`  ==Int== | The number of carts. |
| `total` [ ==MoneyType== ](../../Cart/objects/money-type.md) | The total value of the carts. |
| `lastCartDate`  ==DateTime== | The date of the most recent cart. |
