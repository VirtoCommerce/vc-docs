# SalesRepTopSellerType ==~object~==

This type represents a product in the top sellers ranking.

## Fields

| Field | Description |
|-------|-------------|
| `rank`  ==Int== | The product's position in the ranking. |
| `productId`  ==String== | The Id of the product. |
| `name`  ==String== | The product name. |
| `sku`  ==String== | The product SKU. |
| `imageUrl`  ==String== | A link to the product image. |
| `units`  ==Int== | The number of units sold. |
| `revenue` [ ==MoneyType== ](../../Cart/objects/money-type.md) | The revenue the product generated. |
