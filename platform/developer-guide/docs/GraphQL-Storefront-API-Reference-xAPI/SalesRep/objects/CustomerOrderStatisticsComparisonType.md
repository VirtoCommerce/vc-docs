# CustomerOrderStatisticsComparisonType ==~object~==

This type reports the change in order statistics between two date ranges.

## Fields

| Field | Description |
|-------|-------------|
| `totalChange` [ ==MoneyType== ](../../Cart/objects/money-type.md) | The change in total order value. |
| `totalChangePercent`  ==Decimal== | The percentage change in total order value. |
| `countChange`  ==Int== | The change in order count. |
| `countChangePercent`  ==Decimal== | The percentage change in order count. |
