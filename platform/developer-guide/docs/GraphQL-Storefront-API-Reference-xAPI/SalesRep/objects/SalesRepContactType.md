# SalesRepContactType ==~object~==

This type represents a sales representative.

## Fields

| Field | Description |
|-------|-------------|
| `id`  ==ID!== | The Id of the rep. |
| `firstName`  ==String== | The rep's first name. |
| `lastName`  ==String== | The rep's last name. |
| `middleName`  ==String== | The rep's middle name. |
| `fullName`  ==String== | The rep's full name. |
| `name`  ==String== | The rep's display name. |
| `about`  ==String== | A short description of the rep. |
| `photoUrl`  ==String== | A link to the rep's photo. |
| `emails`  ==[String]== | The rep's email addresses. |
| `phones`  ==[String]== | The rep's phone numbers. |
