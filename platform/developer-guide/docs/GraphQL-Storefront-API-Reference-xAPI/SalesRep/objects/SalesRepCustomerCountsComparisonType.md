# SalesRepCustomerCountsComparisonType ==~object~==

This type reports the change in customer counts between two date ranges.

## Fields

| Field | Description |
|-------|-------------|
| `orderingCustomersChange`  ==Int== | The change in the number of ordering customers. |
| `orderingCustomersChangePercent`  ==Decimal== | The percentage change in ordering customers. |
| `newCustomersChange`  ==Int== | The change in the number of new customers. |
