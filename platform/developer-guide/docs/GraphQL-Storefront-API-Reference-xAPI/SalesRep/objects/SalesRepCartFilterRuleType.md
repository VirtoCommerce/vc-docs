# SalesRepCartFilterRuleType ==~object~==

This type represents a filter for cart statistics.

## Fields

| Field | Description |
|-------|-------------|
| `name`  ==String== | The rule identifier, passed as the `filter` argument, for example `active-carts`. |
| `localizedName`  ==String== | The display name of the filter. |
