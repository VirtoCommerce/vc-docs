# Virto Commerce Cloud

> Cloud sub-index of the Virto Commerce AI documentation hub. Covers Virto Cloud, the managed deployment target for the Platform and Frontend, plus self-hosted cloud patterns (Azure, AWS, on-premise). Includes environment provisioning via portal or CLI, custom module/Frontend deployment, GitOps workflows, and end-to-end "build a store on cloud" walkthroughs. For Platform/backend, Frontend, Marketplace, VC-Shell, or cross-vendor concept mapping, see the parent hub at https://raw.githubusercontent.com/VirtoCommerce/vc-docs/master/docs/llms.txt.

Virto Cloud runs the same `virtocommerce/platform` Docker image used for local Docker development; environments include Elasticsearch, SQL Database, Redis, and File Storage. Custom modules deploy as ZIP artifacts pulled from GitHub releases (or equivalent).
