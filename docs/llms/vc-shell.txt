# Virto Commerce VC-Shell

> VC-Shell sub-index of the Virto Commerce AI documentation hub. VC-Shell is a TypeScript and Vue 3 framework for building custom admin applications outside the legacy AngularJS Backoffice UI. Use it when you need a dedicated admin app for a custom workflow rather than a panel inside the standard admin SPA. For Platform/backend, Frontend, Marketplace, Cloud, or cross-vendor concept mapping, see the parent hub at https://docs.virtocommerce.org/llms.txt.

VC-Shell apps connect to the Platform via REST and GraphQL xAPI. They run as separate SPAs, can be deployed independently, and use generated TypeScript API clients to talk to the Platform.
