# Virto Commerce VC-Shell

> VC-Shell sub-index of the Virto Commerce AI documentation hub. VC-Shell is the Vue 3 + TypeScript application framework for building custom admin (back-office) applications on the Virto Commerce Platform. It provides the authenticated shell, blade navigation, UI components, composables, module runtime, localization, permissions, notifications, and Platform API integration. Use it when you need a dedicated admin app for a custom workflow rather than a panel inside the legacy admin SPA. For Platform/backend, Frontend, Marketplace, Cloud, or cross-vendor concept mapping, see the parent hub at https://raw.githubusercontent.com/VirtoCommerce/vc-docs/master/docs/llms.txt.

VC-Shell apps connect to the Platform via REST and GraphQL xAPI. They run as separate SPAs, can be deployed independently, and use generated TypeScript API clients for typed Platform access.
