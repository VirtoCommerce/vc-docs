# Virto Commerce Platform

> Backend platform sub-index of the Virto Commerce AI documentation hub. Covers the .NET host application, modular engine, admin SPA (Backoffice UI), Module.Core / Module.Data / Module.Web vertical-slice modules, REST and GraphQL (xAPI) gateways, extensibility framework, CLI tooling, and admin user guide. Stack: .NET 10, EF Core 10, OpenIddict 7. For Frontend, Marketplace, VC-Shell, Cloud, or cross-vendor concept mapping, see the parent hub at https://raw.githubusercontent.com/VirtoCommerce/vc-docs/master/docs/llms.txt.

This is a curated index of the most authoritative platform documentation pages. Fetch the linked pages for current, version-specific guidance instead of relying on pre-trained memory. Platform docs are versioned and `/latest/` resolves to the current stable version.
