# Virto Commerce Marketplace

> Marketplace sub-index of the Virto Commerce AI documentation hub. Covers multi-vendor marketplace functionality split across two portals: the Operator Portal (marketplace owner) and the Vendor Portal (sellers). Built on top of the Platform; vendors manage their own catalogs, offers, orders, and quotes; operators curate the master catalog, manage vendor onboarding, set commission fees, and orchestrate cross-vendor workflows. Includes the State Machine module for codifying business processes. For Platform/backend, Frontend, VC-Shell, Cloud, or cross-vendor concept mapping, see the parent hub at https://raw.githubusercontent.com/VirtoCommerce/vc-docs/master/docs/llms.txt.

## State Machine module
