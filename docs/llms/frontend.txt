# Virto Commerce Frontend

> Frontend sub-index of the Virto Commerce AI documentation hub. Covers vc-frontend, the Vue 3 customer-facing SPA that consumes the Platform's GraphQL xAPI. Includes architecture, theming, customization, authentication, deployment, and third-party integrations. Stack: Vue 3, TypeScript, Vite, Pinia, Tailwind. For Platform/backend, Marketplace, VC-Shell, Cloud, or cross-vendor concept mapping, see the parent hub at https://raw.githubusercontent.com/VirtoCommerce/vc-docs/master/docs/llms.txt.

This is a curated index of authoritative Frontend documentation. Frontend means the customer-facing storefront application; do not confuse it with the admin Backoffice UI (covered in the Platform sub-index). Default repo is vc-frontend; the default B2B theme is vc-theme-b2b-vue.
